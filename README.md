# Web de Informes

Portal web para publicar y consultar informes dirigidos a clientes internos y externos.

## Funcionalidades

- Acceso diferenciado para administración y clientes.
- Registro de usuarios y flujos de confirmación y recuperación de cuenta.
- Administración de usuarios y asignación de informes según el acceso correspondiente.
- Carga, organización, edición y publicación de informes.
- Consulta de informes publicados, con opciones para marcarlos como favoritos o revisados.
- Conversaciones privadas sobre cada informe y notificaciones relacionadas.
- Herramientas para descargar e imprimir informes.
- Panel administrativo con resúmenes de actividad.
- Papelera y archivo histórico para informes retirados.
- Asistente con IA para consultar el contenido de un informe y apoyo para editar sus comentarios.
- Herramientas administrativas para ajustar parámetros de facturación de informes.

## Especificaciones técnicas

- **Interfaz:** React 18.
- **Herramientas de desarrollo y compilación:** JavaScript y Vite 7.
- **Autenticación y datos:** Supabase.
- **Funciones de servidor y publicación web:** Netlify.
- **Soporte móvil:** Capacitor para integración con Android.
- **Entorno de desarrollo:** Node.js 20 o posterior.
