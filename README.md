# Web de Informes AMS

**Web de Informes AMS** es un portal para publicar y consultar informes dirigidos a clientes internos y externos.

## ¿Qué permite?

- Organizar y publicar informes para las personas correspondientes.
- Consultar los informes disponibles según el acceso de cada usuario.
- Mantener la comunicación y el seguimiento relacionados con los informes.

El proyecto busca que la entrega y consulta de informes sea más clara y ordenada para quienes los preparan y para quienes los reciben.
